# Deck Building

スマートフォン向けカードゲームを想定したデッキ構築画面のサンプル実装（Unity 6 / URP）。

## 概要

- キャラクターは `Cost` と `HP` を持つ（`Assets/Scripts/Data/CharacterData.cs`）。
- 10体のキャラクターデータをランダムな所持数（最大255）でプレイヤーに付与する。
- 所持キャラクターをドラッグ&ドロップで最大4体までデッキスロットに配置できる。
- デッキの合計コストが10以上になると Total Cost の表示色が変化し、決定ボタン押下時に警告メッセージを表示する。
- ソートボタンで「入手順」「コスト順」「HP順」を循環切り替えできる。

## セットアップ

1. Unity Editor でプロジェクトを開く。
2. メニュー `Tools > Deck Building > Build Scene And Assets` を実行する。
   - キャラクターデータ（ScriptableObject）10体、共通カードPrefab、`Assets/Scenes/DeckBuilding.unity` シーンが自動生成される。
3. 生成された `DeckBuilding` シーンを開いて再生する。

キャラクター/カードの画像素材には [jewel-s.jp](https://jewel-s.jp/) のフリー素材を使用しています。
本リポジトリで実際に画像素材を使用・同梱する場合は、jewel-s.jp が定める利用規約（クレジット表記の要否、商用利用の可否、再配布条件など）を必ず確認の上、その内容をこのセクションに転記してください。
